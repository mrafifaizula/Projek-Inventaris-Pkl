# Deskripsi 
Website ini dibuat menggunakan Bahasa pemrograman C# (.NETCORE) dengan menggunakan template Bootstrap, dan pengelolaan data menggunakan database MySQL atau DBever, Website ini membuat 2 Role Yaitu, Admin yang bertugas untuk mengelola data barang dan mengelola akun staff, kalau Staff yang hanya bertugas untuk mengelola data barang saja.

untuk relasinya untuk barang masuk dan barang keluar memiliki relasi ke data pusat untuk menggambil Nama barang, stok, pemasok, kategori. untuk pemasok sama kategori memiliki relasi ke barang masuk dan barang keluar. 

untuk fiturnya data pusat berfungsu senbagai inti informasi barang, barang masuk untuk untuk mencatat semua barang yang di terima, sedangkan barang keluar mencatat barang yang keluar, sedangkan peminjaman mencatat data barang yang dipinjam, dan pengembalian memantau barang yang telah dikembalikan dan memastikan stok diperbarui, kategori mengelompokan barang berdasarkan kategori, dan pemasok menyimpan informasi tentang pemasok barang.
